# Portfólio Pessoal — Ariane Silvestre

Portfólio desenvolvido para apresentar minha trajetória, formação, habilidades e projetos na área de tecnologia.

## Sobre o projeto

O site reúne informações sobre minha formação em Engenharia de Software, cursos realizados e projetos desenvolvidos na faculdade e no Instituto PROA.

Também possui uma seção de contato para oportunidades, projetos e conexões profissionais.

## Funcionalidades

- Apresentação profissional
- Projetos com links e documentações
- Formação acadêmica e cursos
- Habilidades e ferramentas
- Animações durante a navegação
- Carrossel de projetos
- Formulário de contato
- Layout responsivo

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Swiper.js
- ScrollReveal
- Anime.js
- Remix Icon
